# Code of Conduct

## Our Pledge

We are committed to providing a friendly, respectful, and welcoming environment for everyone.

## Expected Behaviour

- Be respectful to all contributors.
- Use polite and inclusive language.
- Accept constructive feedback.
- Help others learn and improve.
- Respect different opinions.

## Unacceptable Behaviour

- Harassment or discrimination.
- Offensive comments.
- Personal attacks.
- Sharing private information without permission.

## Reporting Issues

If you experience or observe unacceptable behaviour, please contact the repository owner through GitHub.

## Scope

This Code of Conduct applies to all contributors and participants in this project.

## Enforcement

Project maintainers are responsible for reviewing and addressing reported issues fairly and respectfully.
