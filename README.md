# Version Control Systems Practical

This repository contains practical exercises for Markdown, GitHub Wikis, and Code of Conduct.

## Features

- Markdown formatting
- GitHub README documentation
- GitHub Wiki pages
- Code of Conduct

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into the project folder:

```bash
cd EL10-EL11-Practical
```

This repository demonstrates how to:
